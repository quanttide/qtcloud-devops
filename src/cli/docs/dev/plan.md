# plan

## 职责

围绕项目规划文件的命令。扫描 BUGS、ROADMAP、TODO 等项目管理文件，生成变更摘要或进度报告。

## 动机

项目规划分散在多个文件中：BUGS 记录缺陷、ROADMAP 记录迭代计划、TODO 记录待办事项。没有工具能把这些信息汇总起来，开发者需要手动翻文件才能了解项目全貌。

`plan` 填补这个空白。

## 设计

只读命令，不修改任何文件。扫描已知文件路径，解析结构化的内容，输出摘要。

### 默认扫描路径

| 文件 | 用途 |
|------|------|
| `BUGS.md` | 已知缺陷列表 |
| `ROADMAP.md` | 迭代计划与优先级 |
| `TODO.md` | 待办事项清单 |
| `STATUS.md` | 项目当前状态与已知盲区 |
| `CHANGELOG.md` | 版本变更记录（选读，用于上下文） |

### 输出

- BUGS 数量 + 严重程度分布
- ROADMAP 当前迭代进度
- TODO 完成/未完成统计
- 变更对比（操作前后的差异报告）

### 风格

与 `release` 命令组一致：Rust 实现、无副作用、原子操作。
